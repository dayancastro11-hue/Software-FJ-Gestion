# Sistema Integral de Gestión de Clientes, Servicios y Reservas

## Descripción
Proyecto desarrollado para la empresa Software FJ, utilizando Python y programación orientada a objetos.

El sistema permite gestionar clientes, servicios y reservas, aplicando validaciones, excepciones y registro de operaciones.

## Funcionalidades
- Registro y gestión de clientes.
- Manejo de servicios especializados.
- Creación, confirmación y cancelación de reservas.
- Aplicación de polimorfismo y encapsulamiento.
- Manejo de excepciones personalizadas.
- Registro de operaciones mediante archivos de log.

## Tecnologías utilizadas
- Python 3
- Programación orientada a objetos
- Módulo logging

## Ejecución
Descargar el archivo `sistema_software_fj.py` y ejecutarlo desde una terminal:

```bash
python sistema_software_fj.py
```
